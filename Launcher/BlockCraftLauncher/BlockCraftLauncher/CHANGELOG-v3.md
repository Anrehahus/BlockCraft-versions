# BlockCraft Launcher — Black & Purple v3

## Changes in this revision

- Reworked the home page to remove duplicate selected-version information.
- Moved the nickname field into a larger, dedicated game-profile card on the home page.
- Replaced the compact multi-column version cards with full-width library rows.
- Improved the library filter dropdown with an explicit dark visual template.
- Increased the main window layout proportions while keeping it within a more common desktop resolution.
- Enlarged the settings window and simplified its content so the two available settings sections fit without scrolling on typical desktop resolutions.
- Kept the existing installation, launch, deletion, settings persistence, and GitHub version-loading logic.

## Build

Open `BlockCraftLauncher.sln` in Visual Studio on Windows and build the solution. This archive contains source changes; a Windows WPF build was not executed in the authoring environment.
