# BlockCraft Launcher

Настольный лаунчер (Electron) для игры BlockCraft. Версии игры и обновления самого лаунчера берутся из репозитория
**Anrehahus/BlockCraft-versions** (раздел Releases). Лежит в этом репозитории в папке `Launcher/`.

## Для игроков
Скачать `BlockCraft-Launcher-Setup-x.x.x.exe` из релиза **Launcher**, запустить, выбрать папку и ярлыки, и всё: Node.js и прочее ставить не нужно. Дальше лаунчер обновляется сам.

## Как работает автообновление лаунчера
1. В релизе с тегом **`Launcher`** лежат: установщик `.exe`, `.blockmap` и файл `latest.yml` (в нём версия и контрольная сумма).
2. При запуске и раз в час лаунчер читает `latest.yml` и сравнивает версию в нём с собственной (`version` в `package.json`).
3. Если в релизе версия выше: скачивает установщик (только изменившиеся части, благодаря `.blockmap`), проверяет контрольную сумму и показывает в окне «Перезапустить и установить». Если не нажать, обновление поставится при закрытии лаунчера.
4. Установка тихая, без окон установщика, после неё лаунчер запускается снова.

Версии игры устроены иначе: лаунчер читает список всех релизов, находит названия `Pre-classic-rd-…` и `Classic-…` и сравнивает их с установленными папками.

## Выпуск новой версии лаунчера
1. Поднимите `version` в `Launcher/package.json` (например, `2.0.1`) и закоммитьте.
2. Запустите сборку: GitHub → **Actions → Release launcher → Run workflow**, либо `git tag launcher-v2.0.1 && git push origin launcher-v2.0.1`.
3. Через несколько минут установщик и `latest.yml` окажутся в релизе **Launcher**; запущенные лаунчеры подхватят обновление.

Локальная сборка (необязательно): `build-installer.bat` → папка `dist`. Node.js скачается сам.
Для проверки интерфейса без установки: `start.bat` или `BlockCraft.vbs` (без консоли).

## Установщик
Мастер на русском языке: лицензия → выбор «только для меня / для всех пользователей» → папка установки → установка → запуск лаунчера. Создаёт ярлыки на рабочем столе и в меню «Пуск», появляется в «Установке и удалении программ». При удалении ваши игры, миры и скины не трогаются.

## Релизы игры
Название тега или релиза: `Pre-classic-rd-132211`, `Classic-0.0.23a` (регистр и дефисы не важны). К релизу прикрепите **zip** со сборкой (если сборок несколько, добавьте в имя `win`/`linux`/`mac`). Описание релиза показывается во вкладке «Что нового». Версии, уже установленные прежним лаунчером в `%APPDATA%\.BlockCraft\versions`, новый лаунчер подхватывает сам.

## Миры
Игра пишет миры в `saves/world_1…5` внутри папки версии. Чтобы они не пропадали при обновлении и удалении версии, лаунчер хранит их в `worlds/<версия>/`, а `saves` делает ссылкой туда. Раздел «Миры»: копия, копирование и перенос между версиями и слотами, удаление. Подробности в самом разделе («Памятка»).

## Запуск игры
Игре передаётся `-username <ник>`, `-skin <путь к PNG>` (если скин надет) и стандартные флаги Unity (`-screen-fullscreen`, `-screen-width/-height`, графический API). По умолчанию полный экран и разрешение монитора. Имя exe задаётся в `launcher.config.json` (`gameExecutable`), иначе берётся первый найденный.

## Примечания
- Без подписи кода Windows SmartScreen предупредит при первой установке («Подробнее → Выполнить в любом случае»).
- Пиксельный шрифт: положите `pixel.ttf` в `renderer/assets/fonts/` (например, Monocraft).
- Скины: игра принимает PNG ровно 64×64 или 64×32 до 32 КБ; лаунчер передаёт выбранный скин параметром `-skin <путь>`. Тонкие руки игра не поддерживает.
