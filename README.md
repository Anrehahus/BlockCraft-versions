Чтобы установить игру откройте папку Launcher и скачайте BlockCraftLauncher.zip. Разархивируйте ВСЕ файлы в удобное для вас место. Чтобы запустить лаунчер, откройте BlockCraftLauncher.exe
To install the game, open the "Launcher" folder and download "BlockCraftLauncher.zip". Extract ALL the files to a location of your choice. To launch the launcher, open "BlockCraftLauncher.exe".
